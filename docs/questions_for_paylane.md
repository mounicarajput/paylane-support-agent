# Questions for Paylane

The brief left these open. Until answered, the agent follows the safe default shown.

| # | Question | Safe default today |
|---|---|---|
| 1 | After a handoff, how quickly do people reply, who contacts the customer, and how? | Says only that a human has the case. Promises no time, person or channel. |
| 2 | May the agent say how long a refund takes to appear? | Says nothing about timing. |
| 3 | What should it say about pending charges? There is no void tool. | Says pending charges can't be refunded and offers a handoff. |
| 4 | When a customer has no transaction ID, may it search the verified customer's own account by merchant and date (read-only)? | Asks for the transaction ID. |
| 5 | How is a high-priority fraud case marked in your ticket system (a field, a tag, a queue)? | A `[HIGH PRIORITY]` prefix in the ticket summary when the reported loss is over $500. |
| 6 | If a fraud report has no amount, or an amount of $500 or less, what priority should it get? | Hands off at normal priority. |
| 7 | Can the agent see why a card was frozen? | No. It never states a reason. |
| 8 | Is exactly 30 days old meant to escalate? | Yes, as written ("under 30 days"). |
| 9 | Should the $75 limit apply per transaction only, or is there a daily or per-customer cap across several eligible refunds? | Per transaction only. No invented cap. |
| 10 | What wording should it use when a customer mentions suing? | Hands off and gives no legal advice. |
| 11 | Which channel (in-app chat, email, other), languages and hours will it run in? | English, text chat. |
| 12 | How long may transcripts, which can contain customer details, be stored? | Local files only in this exercise. |
| 13 | Can I have 20 to 30 real, anonymized conversations, especially the hard ones? | Own scripted conversations only. |
